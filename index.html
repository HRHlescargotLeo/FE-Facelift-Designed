Frontier Economics · Design phase

Component design concepts

This is the design layer over the signed-off wireframes. Layout, interaction and content order are unchanged — what has been added is colour, typography, imagery and state treatment, drawn from the 2023 Visual Brand Guidelines.

Each component is shown in five routes. A, B and C stay close to the signed-off wireframes and vary the surface treatment. D and E take up the invitation in the updated brief to explore alternative compositions — they change the arrangement, not just the colour. The routes are consistent across every component, so the decision is one decision: pick a route, then adjust it per component.

Everything remains interactive — page the carousels, rotate the banner, click through the accordion index, work the filters. Each component page ends with a tablet and mobile demonstration.

Content and imagery are taken from the live site. Type substitutes Oswald for Steelfish, which is licensed; the live build uses the real face.

The three routes

A — Editorial rule

White surfaces, Midnight display type, Merlot accents and the brand rule device. Refinement rather than reinvention, and the least affected if the colour rationalisation changes the palette.

B — Colour block

Solid brand-colour surfaces with Banana Yellow as the accent. The most visibly redesigned, the most dependent on the palette decision, and the one that asks most of the photography.

C — Soft tint

Tinted surfaces, rounded containers and Peacock accents. Closest to the reference sites Frontier admired, and the most forgiving of uneven source content.

And two that push further. Both answer the brief’s point that the work should solve the underlying problem rather than resemble the wireframe.

D — Broadsheet

Type leads, imagery supports. Oversized Steelfish, numbered indices, outline numerals and hairline rules. Reads as a publication rather than a website listing — and it largely removes the site’s dependence on having a good image for everything.

E — Media card

The social-media card system from the brand guidelines brought onto the site: image block, flat colour, Steelfish caps headline, horizon rule with the written logo and a label, and the Spark cropped at the edge. The most distinctively Frontier of the five.

On the colour rationalisation. The Stage 2 brief is reducing 13 primaries to a smaller core, and the new palette is not agreed yet. Everything here is built on role-based tokens — surface, ink, accent, line — rather than colours hard-coded per component, so when the new palette lands it is a token change rather than a redesign. Route B is the one that would feel the change most, since it leans hardest on individual brand colours as surfaces.

Next

Decisions this pack needs

Which route, and is it one route across all components? Mixing routes per component produces a site that does not read as one system. Our recommendation is to pick a route, then let individual components flex within it.
How far to push. Routes D and E change composition, not just surface. The updated brief explicitly invites that, but both carry implementation consequences noted on each page — worth agreeing the appetite before we develop one of them further.
Steelfish on the web. It needs a webfont licence, and it is a condensed display face that works in caps at scale but fights long headlines. Routes D and E lean on it hardest, so this needs confirming early for those two.
The icon set for image and text. A new icon library is out of scope. Route D removes the need for one entirely and Route E substitutes the Spark, so both offer a way through if the licence question stalls.
Colour palette timing. Everything is built on role-based tokens, so the rationalised palette is a token change rather than a redesign. Route E maps tones to categories, so it needs the final palette before that mapping is fixed.
Carousel library capability. The brief asks whether the existing implementation supports the approved interaction without a second library. All five routes use the same underlying behaviour, so this is one question rather than five.
